04Baixar as imagens

Para alimentar uma IA, o ZIP com todas as imagens é o mais prático. Algumas IAs de chat não abrem ZIP: nelas, use as fotos soltas ou a folha de contato. Use só vídeos seus ou com permissão de quem os fez.

Link temporário para mandar para uma IA

Envia as fotos marcadas para um endereço seu e gera um link que expira. Cada link leva até 130 fotos; se tiver mais, o app divide sozinho em até 4 links. Quem tiver o link vê as fotos até lá, então só mande para quem você quer que veja. Só IAs que abrem links conseguem ler; nas outras, anexe as fotos.
